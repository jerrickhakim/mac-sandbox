### Health check fails

Rebuild the sandbox image if you updated `sandbox-api/`:

```bash
cd sandbox-api
container build -t sandbox:latest .
```

### Platform API returns 401

Make sure you're using the `platformToken` from the sandbox creation response:

```bash
# Wrong - using API token
curl $SANDBOX_URL/__platform/health \
  -H "Authorization: Bearer $TOKEN"  # ❌

# Correct - using platform token
curl $SANDBOX_URL/__platform/health \
  -H "Authorization: Bearer $PLATFORM_TOKEN"  # ✅
```

## CLI Options

```bash
# Start with auto-tunnel (default)
sandbox start

# Custom port
sandbox start --port 8080

# Without tunnel (local only)
sandbox start --no-tunnel

# Generate new pairing code
sandbox pair

# List active tokens
sandbox tokens
```

## Complete Example

````bash
# 1. Install
npm install -g sandbox

# 2. Build sandbox image
cd sandbox-api && container build -t sandbox:latest . && cd ..

# 3. Start server
sandbox start
````
